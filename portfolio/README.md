# Kalifullah Dhameem Ansari Portfolio

Static recruiter-focused portfolio for GitHub Pages, built with React and Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## GitHub Pages deployment

The workflow in `.github/workflows/deploy.yml` builds this folder and deploys `portfolio/dist` to GitHub Pages on every push to `main` or `master`.

Before publishing, replace `public/Kalifullah-Dhameem-Ansari-Resume.pdf` with the final resume PDF using the same filename.
